Software engineer working across the full stack. I build web applications and APIs in TypeScript with React, Next.js and NestJS, backed by relational and document databases, and systems software in Rust and Go, from command-line tools and desktop applications to Linux services. My work covers the whole life of a product: architecture, implementation, testing, delivery and maintenance.

AI is part of that practice as well: agent-based workflows with MCP, local language models, LLM integration into applications and prompt engineering. It sits alongside the core engineering work, which rests on typed code, tested behavior and maintainable architecture.

The software I release publicly is published under [Ordreth](https://ordreth.com).

### How I work

The principles that apply to every project.

| Area | In practice |
|---|---|
| **Design** | State, data flow and module boundaries defined explicitly and enforced by strict typing. |
| **Quality** | Unit, integration and end-to-end tests, static analysis, and fuzzing wherever input is untrusted. |
| **Privacy and security** | Local-first design, audited dependencies, minimal data collection and least privilege by default. |
| **Performance** | Concurrency and resource use designed up front and verified by measurement. |
| **Delivery** | Reproducible environments with Nix, CI pipelines, versioned changelogs and written decisions. |
| **AI-assisted development** | Agents, local models and MCP are part of the workflow, held to the same tests, review and security standards as hand-written code. |
